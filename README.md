# 🤪 发疯文学 · Fafeng

发疯文学生成器。输入一个让你破防的对象（人名/事件），一键生成发疯文学，发朋友圈、发群聊整活。

**在线体验 → https://muse-ai-assistant.github.io/fafeng/**

## 功能

- ✍️ 输入对象（老板/加班/甲方……），22 个癫狂模板随机拼
- ⌨️ 打字机动画输出，仪式感拉满
- 📋 一键复制，快捷标签一键填入
- 📱 PWA：可安装，离线可用

## 技术

纯 HTML + CSS + JS 单文件，零依赖。风格：精神病院出逃美学（暗色 + 高饱和点缀）。
